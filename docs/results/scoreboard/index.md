# Scoreboards

Performance of the submitted models in the perfect-predictor tests, with one page
per training experiment and one table per variable:

- [ESD pseudo-reality](esd_pseudo_reality.md): trained on 1961–1980; perfect
  cross-validation and perfect extrapolation tests.
- [Emulator hist+future](emulator_hist_future.md): trained on 1961–1980 and
  2080–2099; perfect cross-validation and perfect interpolation tests.

See the [Introduction](../../introduction.md#experiments) for the description of the
experiments and tests.
