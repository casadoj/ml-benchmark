# Scoreboard: ESD pseudo-reality

This page compares the models in the ESD pseudo-reality experiment, in which models are trained only on the historical period 1961-1980.

> **Note**. The definitions of the performance diagnostics can be found in the [Evaluate your model](https://casadoj.github.io/ml-benchmark/contributing/evaluation/#metrics) page.

## Perfect model

In this framework models are trained and evaluated with "perfect" predictors: the RCM fields upscaled to the GCM resolution. The tables show the performance in two tests:

* **Perfect cross-validation**: historical period 1981–2000.
* **Perfect extrapolation**: future climate, 2041–2060 and 2080–2099 combined.

A different table exhibits the performace for each target variable: [maximum temperature](#maximum-temperature), [total precipitation](#total-precipitation).

domains. Biases are spatial means of the absolute bias, in the units of the variable.

training experiment, separated by a slash in the order given in  the column header; 
the best value of each test is in bold, and – marks results not  available. 
Models using orography as a predictor are in italics. Type: 
Det. = deterministic, Gen. = generative.

Click a metric to sort the models, best first: the first click sorts by the first test,
the next one by the second test; missing values always go last. Click "Type" to reset
